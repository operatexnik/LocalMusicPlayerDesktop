# ZenMusic Desktop

Десктопная версия локального плеера **ZenMusic** — по мотивам Android-версии.

Тёмная тема, фиолетовый акцент, кружки-обложки, плейлисты, скрытые треки и панель плеера — всё как в мобильной версии, только с нормальным управлением для компьютера.

## Возможности

- Сканирование папки с музыкой (рекурсивно) и мгновенный поиск по названию/исполнителю/альбому.
- Поддерживаемые форматы: **MP3, WAV, FLAC, OGG, AIFF**.
- Чтение тегов и встроенных обложек (ID3/FLAC/OGG).
- Плейлисты: создание, переименование, смена обложки, удаление, добавление/удаление треков.
- «Скрытые треки» с восстановлением выбранных или всех сразу.
- Режимы: повтор всех, повтор одного, перемешивание.
- Перемотка, громкость, следующий/предыдущий трек.
- Ротация обложек плейлистов у треков (раз в минуту), как в Android-версии.
- Трей: при закрытии окно сворачивается, музыка продолжает играть. В трее есть меню управления, а на панели задач остаётся кнопка.
- OpenGL-рендер для одинаково чёткого текста в окне и в максимизированном режиме.
- Горячие клавиши:
  - `Ctrl+Space` — пауза/воспроизведение
  - `Ctrl+→` / `Ctrl+←` — следующий / предыдущий трек
  - `Ctrl+↑` / `Ctrl+↓` — громкость
- Правый клик по треку/плейлисту — контекстное меню. Там же добавление в плейлист и скрытие.

## Запуск из исходников

Нужен **JDK 21** и интернет для первой загрузки зависимостей.

```bat
gradlew.bat :desktopApp:run
```

Либо просто запустите `run.bat` из корня проекта.

## Портативная сборка

Соберите самодостаточную папку с exe и встроенной Java:

```bat
gradlew.bat :desktopApp:createDistributable
```

Результат: `desktopApp\build\compose\binaries\main\app\ZenMusic\ZenMusic.exe`.

Всю папку `ZenMusic` можно скопировать на другой компьютер и запустить
`ZenMusic.exe` — JDK и зависимости уже внутри. Готовые бинарники в репозиторий
не коммитятся (папка `ZenMusic/` и архивы в `.gitignore`).

MSI-установщик (опционально, нужен рабочий WiX `light.exe`):

```bat
gradlew.bat :desktopApp:packageMsi
```

Если MSI не собирается из-за WiX — используйте портативную папку.

## Где хранятся данные

`%APPDATA%\ZenMusic\`

- `state.json` — выбранная папка, плейлисты, скрытые треки, громкость, режим повтора;
- `covers\` — обложки плейлистов.

Треки не копируются и не изменяются — плеер работает с файлами на месте.

## Структура

```
desktopApp/src/main/kotlin/com/zenmusic/desktop/
  Main.kt              — окно, трей, горячие клавиши
  audio/AudioEngine.kt — воспроизведение через Java Sound (mp3spi/jflac/vorbisspi)
  data/                — сканер библиотеки, теги/обложки, хранение состояния
  model/               — Track, Playlist, настройки
  ui/                  — Compose UI: экраны, компоненты, диалоги
```

Старая Android/KMP-заготовка удалена — в проекте осталась только рабочая
десктопная версия.
